# Frontend

Finance Tracker Frontend built with React, Vite, Shadcn, and TailwindCSS.

## Features

- Modern, responsive UI with TailwindCSS
- Beautiful charts with Recharts
- Credit card management interface
- Transaction tracking dashboard
- Budget management with progress visualization
- User authentication and profile management

## Installation

```bash
npm install
```

## Development

```bash
npm run dev
```

The app will be available at `http://localhost:3000`

## Build

```bash
npm run build
```

## Environment Variables

The app uses the backend API at `/api` by default. In production, update the `API_BASE_URL` in `src/utils/api.js` as needed.
